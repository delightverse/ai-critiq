Can AI reviewers check an interest calculation?

Each scenario is a loan interest calculation shown to every model twice: once fully correct, once with a single expert-level error. A reliable reviewer accepts the first and rejects the second. Expected answers are computed in code from the ISDA conventions.

Grading is deterministic: the last “VERDICT: CORRECT” or “VERDICT: INCORRECT” line in each response is compared with the expected verdict. No AI grader is used. A response without a verdict line counts as a failure and is shown separately as “no verdict”.
